# Glossary

### 1. Overview

This glossary provides definitions of technical terms, frameworks, libraries, services, and concepts used in the Signalist application.

It helps developers and readers understand the terminology used throughout the project documentation.

### 2. General Development Terms

| Term                  | Definition                                                                            |
| --------------------- | ------------------------------------------------------------------------------------- |
| Frontend              | The user-facing part of an application.                                               |
| Backend               | The server-side part responsible for application logic and data processing.           |
| Full Stack            | Development involving both frontend and backend.                                      |
| API                   | Application Programming Interface used for communication between software systems.    |
| REST API              | An API architectural style commonly using HTTP methods.                               |
| JSON                  | A lightweight data-interchange format.                                                |
| Environment Variables | Configuration values provided outside application source code.                        |
| Deployment            | The process of publishing an application to an environment where users can access it. |

### 3. Technologies & Frameworks

| Technology   | Definition                                                         |
| ------------ | ------------------------------------------------------------------ |
| Next.js      | A React framework for building web applications.                   |
| React        | A JavaScript library for building user interfaces.                 |
| TypeScript   | A programming language that extends JavaScript with static typing. |
| Tailwind CSS | A utility-first CSS framework.                                     |
| shadcn/ui    | A collection of reusable UI components.                            |
| MongoDB      | A document-oriented NoSQL database.                                |
| Better Auth  | An authentication library for managing user authentication.        |
| Inngest      | A platform for background jobs and event-driven workflows.         |
| Nodemailer   | A Node.js library for sending emails.                              |
| Vercel       | A cloud platform for deploying web applications.                   |

### 4. Financial & Stock Market Terms

| Term           | Definition                                                           |
| -------------- | -------------------------------------------------------------------- |
| Stock          | A share representing ownership in a company.                         |
| Stock Symbol   | An abbreviation used to identify a publicly traded security.         |
| Stock Price    | The current or historical trading price of a stock.                  |
| Watchlist      | A collection of stocks saved for monitoring.                         |
| Price Alert    | A notification triggered by a specified price condition.             |
| Market Data    | Information about financial markets and securities.                  |
| Financial News | News and information related to companies and financial markets.     |
| Stock Analysis | The process of evaluating stock performance and related information. |

### 5. AI & Automation Terms

| Term                         | Definition                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| Artificial Intelligence (AI) | Technology that enables computers to perform tasks associated with human intelligence. |
| Generative AI                | AI systems that generate content such as text, images, or code.                        |
| Google Gemini                | Google's family of generative AI models and services.                                  |
| AI Summary                   | A condensed explanation of information generated using AI.                             |
| Automation                   | Performing tasks with minimal manual intervention.                                     |
| Background Job               | A task executed separately from the immediate user interaction.                        |
| Workflow                     | A sequence of connected operations or tasks.                                           |

### 6. Database & Authentication Terms

| Term           | Definition                                                                        |
| -------------- | --------------------------------------------------------------------------------- |
| Database       | An organized system for storing and managing data.                                |
| Collection     | A grouping of documents in MongoDB.                                               |
| Document       | A record stored in MongoDB, typically using BSON.                                 |
| CRUD           | Create, Read, Update, and Delete operations.                                      |
| Authentication | Verifying the identity of a user.                                                 |
| Authorization  | Determining what an authenticated user is allowed to access.                      |
| Session        | Information representing an authenticated user's interaction with an application. |
| SMTP           | Simple Mail Transfer Protocol, used for sending email.                            |

### 7. API & Deployment Terms

| Term                    | Definition                                                                       |
| ----------------------- | -------------------------------------------------------------------------------- |
| Finnhub                 | A financial data API provider.                                                   |
| API Key                 | A credential used to authenticate requests to an API.                            |
| HTTP                    | Hypertext Transfer Protocol, used for communication between clients and servers. |
| GET                     | An HTTP method commonly used to retrieve information.                            |
| POST                    | An HTTP method commonly used to submit information.                              |
| Webhook                 | An HTTP callback used to notify another system about an event.                   |
| Production Environment  | The environment where the application is deployed for real users.                |
| Development Environment | The environment used to build and test the application.                          |
| Build                   | The process of preparing application code for execution or deployment.           |

### 8. Conclusion

This glossary provides a reference for the terminology used throughout Signalist.

It helps developers, students, and other readers understand the technologies and concepts involved in building and maintaining the application.
