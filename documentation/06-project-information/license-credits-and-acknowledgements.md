# License, Credits & Acknowledgements

### 1. Overview

Signalist is a stock market web application developed as a software project to demonstrate modern web development, external API integration, database management, authentication, and AI-powered functionality.

This section provides information about project ownership, technologies, external services, and acknowledgements.

### 2. Project Information

| Detail               | Information                  |
| -------------------- | ---------------------------- |
| Project Name         | Signalist                    |
| Project Type         | Stock Market Web Application |
| Frontend Framework   | Next.js                      |
| Programming Language | TypeScript                   |
| UI Library           | React                        |
| Styling              | Tailwind CSS                 |
| Database             | MongoDB                      |
| Authentication       | Better Auth                  |
| AI Integration       | Google Gemini                |
| Background Workflows | Inngest                      |
| Hosting              | Vercel                       |
